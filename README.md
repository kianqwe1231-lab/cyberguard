# CyberGuard Android (v0.1)

آنتی‌ویروس اندرویدی با تم هکری — Kotlin + Jetpack Compose.

## اجرا
1. **Android Studio** (Koala یا جدیدتر) → Open → همین پوشه. اجازه بده Gradle sync شود (پوشه wrapper همراه نیست؛ Android Studio خودش می‌سازد).
2. گوشی را با USB Debugging وصل کن یا Emulator بساز → Run ▶
3. VS Code برای ویرایش کد عالی است (افزونه‌ی Kotlin)، ولی بیلد و SDK و امولاتور را Android Studio / خط فرمان Gradle انجام می‌دهد.

## چه چیزی واقعاً کار می‌کند
- اسکن سبک/سنگین برنامه‌های نصب‌شده: مجوزهای پرخطر، سرویس Accessibility فعال، نصب از منبع ناشناس، الگوی SMS+Accessibility، و در حالت سنگین هش SHA-256 فایل APK
- اسکن فوری برنامه تازه‌نصب‌شده (receiver داینامیک)
- اسکن دوره‌ای هر ۱۵ دقیقه با WorkManager + اعلان خودکار
- پایش مصرف: زمان پیش‌زمینه‌ی برنامه‌ها (UsageStatsManager) و هشدار
- اسکن لینک فیشینگ (قوانین ظاهری)

## محدودیت‌های واقعی اندروید
- **پایگاه امضا خالی است** (`Signatures` در Scanner.kt). باید از فید خودت پر شود؛ بدون آن فقط تحلیل رفتاری/مجوزی داریم.
- اندروید درصد باتری هر برنامه را به اپ‌های ثالث نمی‌دهد؛ ما زمان پیش‌زمینه را نماینده گرفته‌ایم.
- اسکن فایل‌های دیگر برنامه‌ها به‌خاطر Scoped Storage ممکن نیست؛ فقط APKها و پوشه‌هایی که کاربر دسترسی می‌دهد.
- گوگل‌پلی برای `QUERY_ALL_PACKAGES` فرم توجیهی می‌خواهد.
- برای محافظت لحظه‌ای پایدار، بعداً Foreground Service اضافه کن.

## قدم‌های بعدی
Foreground Service + اعلان دائمی · ضد سرقت (Device Admin) · قفل برنامه (BiometricPrompt) · ممیزی Wi-Fi (WifiManager) · فید امضا از سرور · ذخیره تاریخچه با Room
